# Food Shorts videos

Drop your vertical (9:16) clips in this folder using these exact filenames
and the Shorts page (shorts.html) will pick them up automatically —
nothing else to wire up.

| Filename            | Currently shows (poster) while you add the real clip |
|----------------------|--------------------------------------------------------|
| short-1-jollof.mp4   | Jollof rice with grilled chicken                       |
| short-2-smallchop.mp4| Small chops platter                                     |
| short-3-spaghetti.mp4| Stir-fry spaghetti                                      |
| short-4-chicken.mp4  | Crispy chicken                                          |
| short-5-moimoi.mp4   | Moi moi                                                 |
| short-6-dessert.mp4  | Ice cream / dessert                                     |

Tips:
- Keep clips short (10–20s), muted-friendly (no dialogue needed — text/captions
  are handled on-screen), and under ~8MB each so they load fast on mobile data.
- MP4 (H.264) is the safest format for broad browser support.
- Until a file exists, that slot just shows its still poster image instead —
  nothing breaks.
- Want more or fewer than 6 shorts, or different dishes? Edit the `SHORTS`
  array at the top of shorts.js — each entry is one card.
